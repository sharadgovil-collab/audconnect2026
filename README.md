# AudConnect 2026 event app

Live site for AudConnect 2026 (SAPS), hosted on GitHub Pages at www.audconnect2026.com.
Data is stored in the Supabase project "audconnect-2026" (Singapore region).

## Files
- index.html: the whole app (design, programme, check in, Q&A, Engage, feedback, certificate, organiser dashboard)
- CNAME: tells GitHub Pages to serve the site on www.audconnect2026.com

## Committee access
Check in with your own first and last name and the company code (ask the SAPS committee).

## Testing before the day
Add ?now=15:20 to the address to preview "Happening now" at any time of day.

## After the event
Export attendance and feedback from the organiser dashboard, then archive this repository and pause the Supabase project.
